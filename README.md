# 🏢 Bob’s Company Landing Page

A modern and responsive landing page for a fictional company named "Bob’s Company". This project was created primarily to **practice and apply SASS (SCSS)** for styling.

🔗 **Live Demo:** [sham-sbehat-bobs-company-landing-page.netlify.app](https://sham-sbehat-bobs-company-landing-page.netlify.app/)

## 📝 Description

This landing page includes:

- Hero section with call-to-action.
- About and services sections.
- Clean, modular layout with reusable style components using SASS.
- Fully responsive and mobile-friendly design.

🎯 **Main Goal:**  
To learn and implement **SASS (SCSS)** features like variables, mixins, nesting, partials, and better CSS structure.
